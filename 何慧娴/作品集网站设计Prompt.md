# 何慧娴 - 大数据管理与应用专业 作品集网站设计 Prompt

---

## 一、项目概述

### 1.1 网站目标
为**何慧娴**（重庆三峡科技大学，大数据管理与应用专业，2027届）创建一个面向HR的个人作品集网站，展现其在**数据分析、大数据工程、AI/算法、数据全栈**四个方向的核心竞争力，帮助其在校招中脱颖而出。

### 1.2 目标岗位
- 数据分析师
- 大数据工程师
- AI/算法工程师
- 数据全栈工程师

### 1.3 技术实现要求
- **纯静态页面**：HTML5 + CSS3 + 原生JavaScript，无框架依赖
- **零构建工具**：直接打开 `index.html` 即可预览
- **响应式设计**：适配桌面端（1920px/1440px）、平板（768px）和手机端（375px）
- **浏览器兼容**：Chrome、Edge、Firefox、Safari 最新版本

## 二、设计风格规范

### 2.1 整体定位：现代科技风 + 数据叙事感

**关键词**：深邃、流动、精确、数据感、未来感

### 2.2 色彩系统

```
背景主色：  #0a0e1a（深邃夜空黑蓝）
背景辅色：  #111827（卡片/区域底色）
强调色1：   #00d4ff（电光青 — 主CTA、标题高亮、hover）
强调色2：   #7c3aed（紫罗兰 — 次强调、图标渐变）
渐变主体：  #00d4ff → #7c3aed（头部、按钮、数据环）
成功绿：    #10b981（技能进度、指标向上）
警告橙：    #f59e0b（中等级别标注）
文字主色：  #e2e8f0
文字辅色：  #94a3b8
文字弱色：  #64748b
```

### 2.3 字体系统

```css
--font-display: 'Inter', -apple-system, sans-serif;       /* 大标题、Hero */
--font-body: 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif;  /* 正文 */
--font-mono: 'JetBrains Mono', 'Fira Code', 'Consolas', monospace;  /* 代码块、数据数字 */
```

### 2.4 视觉元素

- **粒子背景**：Canvas 实现深色背景上缓慢漂浮的粒子网络（类似数据节点连接）
- **霓虹光效**：关键元素 hover 时出现 `box-shadow` 电光青辉光
- **数据流动线条**：section 之间用 SVG 波形/折线过渡，模拟数据流动
- **网格叠加**：背景层有微弱的科技网格线（`rgba(0,212,255,0.03)`）
- **卡片**：半透明深色底 + 1px 半透明边框 + backdrop-filter 模糊
- **图标**：使用 Font Awesome 6 免费图标集

**每个项目的模态框内容详情**（根据PDF内容提炼）：

**1. 电商实时数据分析系统**
- 背景：解决电商平台T+1数据延迟问题，实现秒级实时分析
- 目标：构建实时数据处理Pipeline，支持PV/UV/转化率多维度分析
- 技术方案：Kafka(数据采集) + Spark Structured Streaming(流计算) + Redis(缓存) + Streamlit(可视化)
- 亮点：Watermark机制处理迟到数据、Redis ZSet实现TopN排行、2秒刷新仪表盘、Spark Join优化解决Update模式限制

**2. 基于YOLO的车牌检测与猫狗识别**
- 背景：深度学习目标检测在安防和宠物识别的实际应用
- 目标：训练YOLO模型实现车牌检测和猫狗分类，并部署为Web应用
- 技术方案：Ultralytics YOLO + Django REST API + OpenCV图像处理 + HTML/CSS/JS前端
- 亮点：CCPD数据集车牌定位、Kaggle猫狗60 epochs训练、Base64图像传输、车牌mAP达78%

**3. 基于通义千问的智能对话机器人**
- 背景：探索大语言模型在实际对话场景中的应用
- 目标：基于Qwen-Max构建支持流式/阻塞两种模式的智能对话系统
- 技术方案：Django + DashScope API + SSE流式响应 + System Prompt工程
- 亮点：SSE实现流式输出（首Token延迟<0.5s）、双模式对比（Stream vs Block）、Prompt上下文设计、Generator yield机制

**4. 城市交通流量管控及优化策略**
- 背景：城市交通拥堵问题日益严重，需数据驱动的优化方案
- 目标：分析863,192条交通数据，提出流量优化策略
- 技术方案：Python Pandas + Sliding Window算法 + Folium热力图 + Demand-Supply模型
- 亮点：巡游车辆识别算法、20%车辆造成主要拥堵、优化后通行时间减少25%-39%、KL散度验证空间分布(p<0.01)

**5. 环保标准提高对中小企业生存压力分析**
- 背景：环保政策趋严，量化其对中小企业的影响
- 目标：用统计和计量方法评估环保标准对中小企业生存的影响
- 技术方案：Logistic回归 + Cox比例风险模型 + Pearson相关 + T检验
- 亮点：112.3%成本上升显著(p<0.001)、退出风险增87%(OR=2.79)、多维相关性分析(r=-0.92 to 0.99)

**6. 购物分析网站**
- 背景：电商数据蕴含丰富用户行为模式，需系统化分析平台
- 目标：构建一个完整的电商数据分析Web应用
- 技术方案：Flask + Plotly + Scikit-learn(RF/KMeans/PCA) + Pandas
- 亮点：文件上传自动解析、数据预处理Pipeline、RF购物预测 + KMeans用户聚类、24h结果缓存机制

## 五、动效与交互设计

### 5.1 页面加载动画

- 首页加载时，粒子背景先出现 → Logo & 导航淡入 → Hero区域元素依次动画
- 其余页面：进入时 section 从下方 30px 淡入上浮（`Intersection Observer`）

### 5.2 滚动效果

- **视差滚动**：Hero区域的Canvas粒子层滚动速度略慢于前景（可选）
- **滚动显示**：所有卡片/进度条等元素，进入视口时触发动画
- **平滑滚动**：锚点链接使用 `scroll-behavior: smooth`

### 5.3 交互反馈

| 元素 | Hover效果 |
|------|-----------|
| 导航链接 | 电光青下划线从左滑入 |
| 按钮（主） | 渐变位移 + 辉光扩散 |
| 按钮（次） | 边框变亮 + 内部微光 |
| 项目卡片 | 上浮4px + 辉光边框 + 背景变亮 |

## 八、关键代码模块提示

### 8.1 粒子背景（particles.js）
- 使用 `requestAnimationFrame` 循环绘制
- 粒子类：`{x, y, vx, vy, size, opacity}`
- 鼠标位置全局存储，粒子在鼠标附近加速
- 粒子之间距离<150px时绘制半透明连线
- Canvas 尺寸响应 `window.innerWidth/Height`，监听 resize

### 8.2 数字滚动（counter.js）
- 目标数值存在 `data-target` 属性
- 使用 `requestAnimationFrame` 实现 easeOutExpo 缓动
- `Intersection Observer` 触发，只执行一次

### 8.3 雷达图（radar.js）
- Canvas 绘制五边形，每个顶点代表一个技能维度
- 填充区域为半透明渐变
- 动画：从中心向外展开到目标值
- 顶点标注文字

### 8.4 项目筛选（projects.js）
- 点击筛选标签，获取 `data-category`
- 遍历卡片，匹配的保持显示，不匹配的添加 `filtered-out` class（缩小+淡出）
- 过渡时间 0.4s

### 8.5 模态框（projects.js）
- 点击"查看详情"动态创建模态框DOM
- 内容从 `data-project` 属性和预设数据对象获取
- ESC 或点击遮罩关闭
- 打开时禁止body滚动
