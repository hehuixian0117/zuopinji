# 我的数据分析与AI项目作品集

欢迎浏览我的项目仓库！这里存放了我本科期间完成的几个主要课程项目，涉及交通流量优化、电商数据分析、环保政策量化、计算机视觉应用等方向。

## 📁 项目列表

1.  **[城市交通流量管控及优化策略研究](城市交通流量管控及优化策略研究.pdf)**
    -   采用绿波协调控制模型与滑动窗口算法，对城市复合型交通区域进行了系统性优化。
2.  **[电商实时数据分析系统](电商实时数据分析系统.pdf)**
    -   基于 Kafka + Spark + Redis + Streamlit 技术栈，构建了高并发用户行为实时分析看板。
3.  **[购物分析网站](购物分析网站.pdf)**
    -   基于 Flask 框架开发的 Web 端购物数据探索性分析工具，支持多维度可视化。
4.  **[环保标准提高对中小企业生存压力的量化分析](环保标准提高对中小企业生存压力的量化分析.pdf)**
    -   利用 Logistic 回归与 Cox 比例风险模型，量化了环境规制对中小企业的影响机制。
5.  **[基于 YOLO 的车牌检测与猫狗识别系统](基于YOLO的车牌检测与猫狗识别系统.pdf)**
    -   基于 YOLO 算法的 Django Web 应用，实现了图片中车牌检测和猫狗分类功能。
